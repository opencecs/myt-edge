# Development handoff

Use the [repository guide](REPOSITORY-GUIDE.md) to locate source changes and the [dual-board build guide](DUAL-BOARD-BUILD.md) to prepare an image. Build with the selected board and its corresponding kernel device tree and binary inputs.

Before publishing an image, record the three source commits, per-board input hashes, the output archive hashes, and the results of build, package and installation checks. Report an on-device result only for the board and version actually tested.
