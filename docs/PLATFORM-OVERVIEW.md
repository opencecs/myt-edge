# MYT Edge platform

MYT Edge provides a Debian system for Y4 and Y12. The board service exposes model-specific hardware state through the [board API](board-api.md). Choose the board explicitly during the [build](DUAL-BOARD-BUILD.md) and use the corresponding kernel, device tree and firmware inputs.

[Board differences](Y4-Y12-DIFFERENCES.md) documents model-specific behavior.
